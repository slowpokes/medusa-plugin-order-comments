## [0.1.0] - 2026-09-17

### Added

- Order details widget with an inline comment editor.
- Complete newest-first comment history and latest-comment marker.

- Admin author attribution with a name and email snapshot.
- Dedicated module, generated database migration, workflow, and tests.
